CERTIFIED AUTHORITY BOUNDARIES

Router:
- decides whether Small or Big would be useful
- consumes normalized semantic evidence only
- observes already-resolved Reasoning
- cannot mutate Reasoning
- does not inspect Governor state
- does not inspect resource availability
- does not perform runtime/session work

Model Form:
- exact-turn override outranks Auto
- matching Task override outranks Auto
- pinned baseline outranks Auto
- Auto participates only when canonically eligible
- explicit/unavailable forms fail closed
- no silent semantic downgrade

Governor:
- receives the exact frozen ResourceRequest
- cannot rewrite Model Form
- cannot rewrite Reasoning
- APPROVE permits runtime continuation
- DEFER stops before runtime/session side effects
- DENY stops before runtime/session side effects
- resource pressure does not trigger rerouting

Retry/recovery:
- Reasoning resolves once per meaningful turn
- Auto router runs once per meaningful turn
- Model Form freezes once
- stale recovery uses the SAME FrozenModelFormTurn
- replacement session keeps frozen semantic identity
- one stale retry only
- retry failure does not reroute
- second stale failure does not reroute

Isolation:
- recommendations are Task-local
- recommendations are execution-context-local
- Task mismatch fails closed before freeze/runtime
- execution-context mismatch fails closed before freeze/runtime
- separate Tasks/contexts route independently

Reasoning/Form independence:
- Deep does not mechanically imply Big
- Light does not mechanically imply Small

Resource boundary:
- ResourceRequest is downstream of frozen Reasoning and Model Form
- Governor cannot silently change Big to Small
