## Key recovered invariants

- Source Context is Forest-owned, not Learning-owned and not runtime-owned.
- Runtime receives one already-frozen final instruction string.
- No Source Context means exact Learning passthrough.
- Source material has reference-data authority and cannot override user instruction, Forest policy, permissions, or higher-priority authority.
- Exact region IDs win before labels.
- Ambiguous labels fail closed.
- No fuzzy guessing is required for exact structural targeting.
- Expansion is bounded and ancestor-only.
- No whole-source fallback occurs unless explicitly requested.
- Paths are hidden by default.
- Once the final instruction snapshot exists, stale runtime recovery must not reopen Source Context, Learning, or Hot Context computation.
