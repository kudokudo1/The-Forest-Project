FINAL COLONY SEMANTICS

1. Colony
A Colony is one Tree and all of its Clones/Ramets.

2. Tree identity
tree_id identifies the Tree/Colony.

3. Colony-member identity
execution_context_id is the canonical stable technical identity
for an individual Ortet/Ramet execution context.

4. Lineage and operational role
lineage_role records ortet/ramet lineage.
operational_role records Main/worker/specialist/etc.
Lineage does not determine operational role.
A Ramet may be Main while the Ortet remains the Ortet.

5. Runtime session identity
A live runtime session belongs to:
execution_context_id + binding_id

Two Colony members using the same binding must retain separate
runtime sessions, context/KV, and control state.

6. Shared model residency
Model residency belongs to the binding/model weights, not to
an individual Tree member.

Multiple execution contexts may share one resident model-weight
copy while preserving separate runtime sessions.

7. Model Form
Model Form is execution-context local.

8. Reasoning
Reasoning control and temporary Reasoning leases are
execution-context local.

Legacy top-level reasoning_control is compatibility state for
ctx-default only and must never broadcast to Ramets.

9. Task-local state
Active Task state, Workshop behavior, temporary capabilities,
and task-sticky Skills remain context-local.

10. Resource targeting
ResourceRequest.execution_context_id comes from the frozen turn.
Resource allocation therefore targets the exact active
execution context rather than the Tree name.

11. Lifecycle
Create, reuse, stale recovery, rotation, retirement, and
non-stale failure remain scoped to the intended context+binding
session. Neighboring Colony members remain untouched.

12. Shared capability, separate activation
Trees may share durable capability and model resources while
temporary/live activation remains scoped to the execution context.

13. Phase boundary
14.11H certifies Colony identity, state isolation, runtime-session
ownership, shared-weight semantics, resource targeting, and
lifecycle composition.

Fake-adapter execution certification belongs to 14.11I and is
not claimed by this checkpoint.
